# Backlog — reference server

Work is organised by feature, then by task.

- `features/` — scoping (`overview.md`) and design (`technical.md`) per feature.
- `tasks/` — unit implementation tasks, one GitHub issue each (in `ekoz-chat/server`).
- `todo.md` — delivery order, one table per feature.

Global documentation (functional spec, protocol, ADRs) lives in the
[`spec`](https://github.com/ekoz-chat/spec) repository.

The `backlog-*` skills maintain this structure; run them and `implement-issue`
from this repository.
