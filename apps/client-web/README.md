# @ekozhq/client-web

Ekoz demonstration web client. Exercises every server feature as it ships. Talks to the server exclusively through `@ekozhq/sdk`.

Stack: React, Vite, TypeScript, Tailwind CSS 4, Vitest. See [ADR 0016](../../docs/technical/adr/0016-web-client-stack.md).

```bash
bun run --filter @ekozhq/client-web dev
```
