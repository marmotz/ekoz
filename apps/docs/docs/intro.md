# Guides

Ekoz is an open chat protocol with a reference server, an SDK and a demonstration
web client. These guides are for the people who run and build on it.

The Guides always describe the latest version of the reference server. The
[Protocol](/protocol/) and [SDK](/sdk/intro) documentation are versioned.

## Where to start

- **Try it**: the [quickstart](getting-started/quickstart.md) connects a minimal client
  to a local server in a few minutes.
- **Run a server locally**: [installation](getting-started/installation.md).
- **Operate a server**: [deployment](server/deployment.md),
  [configuration](server/configuration.md) and [operations](server/operations.md)
  (backups, monitoring, updates).
- **Harden it**: the [security](security.md) checklist.
- **Common questions**: the [FAQ](faq.md).
