# Changesets

This folder has been automatically generated by `@changesets/cli`, a tool that
manages the changelog and versioning for this package.

With the [`@changesets/cli`](https://github.com/changesets/changesets) tool, add a
changeset for every visible change (`AGENTS.md` requirement):

```
bun run changeset
```

npm publishing is deferred until the SDK surface stabilises (ADR 0025); until
then changesets only feed `CHANGELOG.md` and the SemVer bump.
